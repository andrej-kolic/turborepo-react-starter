# Security Policy

## Report a vulnerability

Report it privately through [GitHub's private reporting form](https://github.com/andrej-kolic/turborepo-react-starter/security/advisories/new), not in a public issue. Include what is affected, how to reproduce it, and its impact.

## Supported versions

Only the latest commit on `develop` is supported. A project built from this starter takes fixes by applying them to its own copy.
